# parvizmoin.ir — بسته‌ی به‌روزرسانی

## چیزی که در این پوشه هست
- `index.html` — نسخه‌ی جدید سایت با هر دو بنر (الکامپ + دورهمی آزادکاران) کنار هم
- `banner.png` — پوستر بنر الکامپ (مستقیم از ریپوی گیت‌هاب گرفته شده)
- `banner2.png` — پوستر بنر دورهمی آزادکاران
- `publish.sh` — اسکریپت انتشار/به‌روزرسانی

## دستورات Git Bash

اگر ریپو از قبل روی هارد کلون شده (مثلاً در `/o/dev/parvizmoin.ir`):

```bash
cd /o/dev/parvizmoin.ir
```

کپی کردن فایل‌های این بسته داخل همون پوشه (جایگزین `index.html` قدیمی، اضافه‌کردن `banner2.png`)، سپس:

```bash
git add .
git commit -m "add: بنر دورهمی آزادکاران کنار بنر الکامپ"
git push
```

اگر ریپو هنوز روی هارد نیست و می‌خوای از صفر کلون کنی:

```bash
git clone https://github.com/parvizrahayan/parvizmoin.ir.git
```

بعد فایل‌های این بسته رو داخلش کپی کن و همون سه دستور بالا رو بزن.
